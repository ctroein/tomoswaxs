# Infrastructure logos

Official logos bundled unchanged for collaboration credits in About.
The logos retain their original owners’ rights. About renders InfraVis and NAISS
lettering with the theme’s text colour; InfraVis retains its colour gradient.
MAX IV uses its original grey and orange colours on a white backing in both
themes. The bundled files remain unchanged.

- InfraVis: `white text.svg` in https://infravis.se/wp-content/uploads/2026/02/InfraVis-logo.zip
  (linked from https://infravis.se/branding/).
- MAX IV: https://www.maxiv.lu.se/wp-content/uploads/2024/08/MAX-IV_logo1_cmyk-1024x421.png
  (shown at https://www.maxiv.lu.se/about-us/press-room/).
- NAISS: https://www.naiss.se/wp-content/uploads/2023/07/naiss_logo_white.png
  (site logo at https://www.naiss.se/).

The About dialog displays MAX IV through an SVG viewport that excludes the
PNG’s transparent bottom padding, centring the visible artwork.
